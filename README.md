# NFSU2 Co-op

**Один город. Две машины. Совместная карьера.**

Кооперативный мод для оригинальной PC-версии Need for Speed: Underground 2.

**0.5 Alpha** · **Windows x86** · **2 игрока** · **LAN / Radmin VPN**

[Установка](docs/INSTALL.md) · [Известные проблемы](docs/KNOWN-ISSUES.md) · [Изменения](CHANGELOG.md) · [Сборка](docs/BUILD.md)

</div>

---

> **Экспериментальная версия.** Мод развивается на основе реальных заездов двух игроков. Последний пакет собран, но не проверен в игре. Возможны вылеты, рассинхронизация и проблемы загрузки транспорта. Сохраните резервную копию профиля перед использованием.

## Скачать и начать

Откройте **Releases** этого репозитория и скачайте ZIP мода из **Assets** у последнего предварительного релиза. Архивы GitHub **Source code** предназначены для разработчиков.

1. Установите одинаковую поддерживаемую версию игры и ASI Loader на обоих ПК.
2. Распакуйте ZIP мода в отдельную папку и запустите `START.cmd`.
3. Выберите папку игры, ник и роль: один **Хост**, другой **Клиент**.
4. В LAN клиент вводит IPv4 хоста. Через Radmin VPN оба указывают VPN-адрес друг друга.
5. Установите одинаковые настройки функций, нажмите **«Установить и играть»** и выйдите в город в карьере.
6. Хост выбирает гонку. Клиент принимает приглашение клавишей **F7**, отменяет — **F8**.

Подробности: [установка, адреса и подключение](docs/INSTALL.md).

## Что реализуется

| Возможность | Текущее состояние |
| --- | --- |
| Общий открытый мир | Два игрока видят движения друг друга; подтверждено предыдущими игровыми сеансами |
| Совместные карьерные гонки | Есть запуск, ручное управление, результаты и возврат; предыдущие совместные заезды завершались успешно |
| Свои автомобили и тюнинг | Передаются конфигурация и характеристики; загрузка в катсцене и некоторые детали требуют проверки |
| Общий трафик и столкновения | Реализованы; невидимые препятствия на клиенте остаются открытой проблемой |
| Места, ники и награды | Реализованы общая таблица, ники, раздельный бюджет и равный командный приз |
| Разные контракты | Обмен доступными гонками и временные маркеры друга без смены своего спонсора |
| Другие режимы и URL | Есть адаптеры режимов и переходов этапов; полной матрицы игровых проверок нет |
| Общая пауза гонки | Согласованная остановка; последняя правка направлена против скачка после фриза |

Наличие реализации не означает, что все сценарии уже стабильны. [Открытые проблемы и границы проверки](docs/KNOWN-ISSUES.md).

## Требования

- Windows и собственная копия игры с поддерживаемым `SPEED2.EXE` (v1.2 NA, проверяется по SHA-256).
- Установленный ASI Loader (`dinput8.dll`). В пакет мода он не входит.
- Одинаковый пакет мода у обоих игроков; доступ к UDP **47210**.
- Одна локальная сеть или общая сеть Radmin VPN. В одной LAN VPN не требуется.

Это нативный ASI-мод. Браузер для игры не нужен. Игра, её ресурсы и сохранения в репозиторий и релиз не включены.
