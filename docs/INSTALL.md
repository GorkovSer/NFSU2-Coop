# Установка и совместная игра

## До запуска

На обоих ПК нужны собственная игра и ASI Loader (`dinput8.dll`). Сохраните копию профиля. Закройте игру перед обновлением мода.

Поддерживается точный EXE с SHA-256:

```text
fa940fe56c8af619a62e6c9cba5c552a01832424a7ee2189af9814d3c531a38f
```

Лаунчер проверяет EXE автоматически. Другие исполняемые файлы не поддерживаются; мод не содержит и не скачивает игру.

## Установка

1. Скачайте ZIP из Assets предварительного релиза и распакуйте **целиком** в новую папку, например на рабочий стол.
2. Запустите `START.cmd`. Оставьте `CoopLauncher.ps1` и папку `payload` рядом с ним.
3. Лаунчер ищет игру автоматически. Если копий несколько, выберите нужную. Если не нашёл — укажите папку вручную через «Выбрать».
4. Введите ник латиницей и выберите роль. На втором ПК должна быть противоположная роль.
5. Настройте адреса по таблице ниже. На обоих ПК выберите одинаковые функции трафика и столкновений; общую паузу оставьте включённой.
6. Нажмите «Установить и играть». При запросе Windows разрешите игре сетевой доступ в используемой частной сети.

## Какой IP вводить

| Сеть | Хост | Клиент |
| --- | --- | --- |
| Одна LAN / Wi-Fi | Адрес можно оставить пустым | Локальный IPv4 хоста, например `192.168.1.17` |
| Radmin VPN | VPN-адрес клиента `26.x.x.x` | VPN-адрес хоста `26.x.x.x` |

Для LAN адрес хоста можно посмотреть командой `ipconfig` на ПК хоста: нужен IPv4 активного сетевого адаптера. Не вводите `localhost`, `127.0.0.1` или адрес самого клиента. В Radmin оба ПК должны находиться в одной VPN-сети. Мод использует UDP `47210`.

## Как начать гонку

Оба игрока выходят в город из карьеры. Хост выбирает доступную гонку обычным способом. Клиент принимает приглашение **F7**; **F8** отменяет приглашение. Не начинайте приглашение во время активной дуэли Outrun. Для первого подключения используйте Circuit — этот сценарий уже проходился на двух настоящих клиентах в предыдущих сборках.

Чужие контрактные гонки добавляются как временные маркеры; свой спонсор и собственные разблокировки сохраняются. Если карта уже открыта, закройте и откройте её. Лимит общего нативного кэша — 64 маркера с учётом магазинов; будущие районы автоматически не открываются.

## Обновление

Обновляйтесь **оба одним и тем же ZIP**. Распакуйте новый пакет в отдельную папку, закройте игру и снова установите мод через лаунчер. Не переносите лабораторные INI, LabBoot или сохранения разработчика.

## Если что-то пошло не так

- Игра не найдена: выберите папку вручную; неподдерживаемый EXE лаунчер отклонит.
- Нет подключения: проверьте роли, адреса, одинаковые сборки и доступ UDP 47210.
- Невидимое препятствие, зависший старт или вылет: сохраните логи обоих игроков после одного сеанса; см. [оформление отчёта](../CONTRIBUTING.md).

Текущие ограничения перечислены в [KNOWN-ISSUES.md](KNOWN-ISSUES.md).
