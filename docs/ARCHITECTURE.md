# Архитектура

| Область | Путь |
| --- | --- |
| Протокол, сессии, кооперативная гонка | `work/nfsu2-web/runtime/` |
| Native hooks, автомобили, ресурсы, контакты | `work/nfsu2-web/win/roam_asi/` |
| Генерация адаптера под точный EXE | `work/build-native.py` |
| Windows-лаунчер | `work/coop-launcher.ps1` |
| Автономные harness и проверки | `work/*-tests.c`, `work/*-offline.c`, `work/nfsu2-web/tests/` |
| Упаковка и идентификация исходников | `work/package-coop.py`, `work/source_provenance.py` |

Сетевой поток обменивается сообщениями и обновляет протокольное состояние. Обращения к игровым объектам, загрузчику и нативной физике выполняются на игровом потоке.

Хост согласует участников и состояние совместной гонки. У каждого игрока сохраняются собственные управление, профиль и бюджет. Транспорт реплик требует отдельной проверки жизненного цикла: совпадение указателя без проверки мира, тела и ресурсов не доказывает, что объект всё ещё тот же.

Пауза гонки использует состояние готовности обоих игровых потоков и подтверждённое время продолжения. Коллизии допускаются только при свежем состоянии и готовой физике; это не разрешение принудительно активировать незагруженные тела или сектора.

Исходные каталоги сохранены от upstream для совместимости build-скриптов. Этот snapshot предназначен для native Windows co-op, а не для сборки браузерного порта.
