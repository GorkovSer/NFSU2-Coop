# История изменений

## 0.5 Alpha · Garage / Race Pool · 2026-10-28

Предварительный релиз; игровые проверки не проводились.

- Быстрый вход использует однократную штатную команду выхода из гаража в город.
- Резерв памяти машин применяется ко всем трём режимам загрузки, включая гонки; раньше увеличивался только первый элемент таблицы.
- Проверка видимости клиентского трафика распознаёт сменившееся физическое тело по списку машин мира.
- Включены быстрый вход с выбранным профилем и повтор потерянного события запуска предгоночной катсцены из предыдущих обновлений.

Краши графических ресурсов `4937f2` / `4939e5` остаются открытыми. Полное устранение невидимых препятствий и нехватки памяти в игре не подтверждено. Автоматическая синхронизация прогрессии сохранений ещё не реализована.


## 0.5 Alpha · Race Pause Boundary · 2026-10-25

Предварительный пакет, игровая проверка ожидается.

- Проверка общей паузы выполняется до расчёта нативного игрового времени.
- Остановка сохраняется до границы следующего игрового кадра; сетевое возобновление не освобождает физику посреди остановленного кадра.
- Переходный кадр после паузы не начисляет накопленное время физике.
- Согласование возобновления сокращено с 2 до 1 секунды с сохранением подтверждений.
- Свободный режим этими изменениями не затронут.

## Предыдущие изменения 0.5 Alpha

- Client Contact Gate: проверка актуальной позы, тела, модели и привязки рендера клиентского трафика перед обработкой контакта.
- NIS Start: ожидание автомобиля друга до начала обычной предгоночной катсцены.
- Drift Intro: строка реального дополнительного участника в downhill-таблице результатов.
- Contract Entry: обработка входа в чужие контрактные гонки и обновления карты.
- URL Contracts: очистка предыдущего этапа и объединение доступных каталогов гонок без отражения чужих маркеров обратно владельцу.
- Автопоиск папки игры, загрузка ресурсов дисков, диагностика вылетов, сетевые результаты и раздельные бюджеты.

Пункты описывают внесённый код. Непроверенные результаты и открытые дефекты перечислены в [известных проблемах](docs/KNOWN-ISSUES.md).
